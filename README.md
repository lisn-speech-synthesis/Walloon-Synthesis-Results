# Walloon Speech Synthesis – Results

Analysis notebooks for the paper *Speech synthesis for Walloon, an under-resourced minority language* (SSW 2025, [doi:10.21437/SSW.2025-29](https://doi.org/10.21437/SSW.2025-29)).

- `bootstrapping.ipynb`: bootstrap confidence intervals for the objective speech metrics (e.g. PESQ, MCD).
- `pauses_test.ipynb`: speech and silence segment measurements in natural vs. synthesised speech.

Model code: [Walloon-Synthesis-VITS](https://github.com/lisn-speech-synthesis/Walloon-Synthesis-VITS).
